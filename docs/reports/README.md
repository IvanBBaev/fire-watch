# Checkpoint reports

Dated checkpoint artifacts for GATES §4 (CP1–CP3). Each checkpoint is decided on its date from
the files here, not from impressions. A criterion without its evidence artifact counts as
missed.

Rules:

- One protocol per checkpoint, written before the checkpoint and **frozen** once committed.
  A correction is a new dated file that names the one it corrects.
- One report per checkpoint date: `cp<N>-YYYY-MM-DD.md`. It quotes the protocol, the config
  versions and digests it ran under, and its evidence tables.
- Nothing here is deleted. A withdrawn report stays, marked as withdrawn.
