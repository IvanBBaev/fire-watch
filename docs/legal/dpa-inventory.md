## 3. Obligations per contracted processor (Art. 28(3) checklist)

For D1, D2 and D5, confirm before first production personal data:

- [ ] DPA accepted and archived (PDF + date) under `docs/legal/signed/` (outside git if confidential).
- [ ] Subprocessor list reviewed; change-notification channel subscribed.
- [ ] Region pinned to the EU and recorded here.
- [ ] Breach-notification term (processor → us) is "without undue delay"; contact recorded
      in [breach-runbook.md](breach-runbook.md) §6.
- [ ] Deletion at the end of the contract.
- [ ] Backup retention on the provider side is ≤ 30 days, or configurable (05 §6 Q2).
