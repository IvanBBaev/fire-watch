# Founder decisions 2026-10-30 — data science, detection and source policy

The founder delegated every decision that analysis can settle (TASKS "Pending founder
decisions", 2026-10-30). This file records the rulings for the data-science, detection and
source-policy domain. Each ruling is conservative: a missed fire costs more than a false
alarm, and when the data is not there, the product says so. Where data is missing, the row
names a rule, a provisional value, and the data that will revise it.

"Implemented in" names the commit-level change or the follow-up item. "—" means the ruling
is a reading of an existing doc and changes no code.
