# Founder decisions 2026-10-30 — thresholds, budgets and operations parameters

Scope: every open threshold, budget, retention and operations parameter that analysis of
the corpus can settle. A value marked **provisional** is the rule's current number; it
moves only by a config version bump, and the "Revisit when" column says which data would
move it. Decisions that need a real-world act (money, a named person, counsel, a deployed
probe) are listed under **Still owner action** and are not decided here.

Principles applied throughout: safety first (page early, never disarm a guard by
default), honesty first (a missing reading reports `no_data`, never "ok"), budgets are
never raised to fit the code (CI-12), and no invented number where the corpus or a
shipped capacity already implies one.
